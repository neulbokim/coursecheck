# CourseCheck Web

CourseCheck의 배포용 웹앱입니다. 2026학년도 2학기 개설과목 1,482개를 정규화해 일반 전공과 연계전공별 시간표를 만듭니다.

## 실행

```bash
npm install
cp .env.example .env.local
npm run dev
```

## 확인

```bash
npm run build
npm audit --omit=dev
```

## 데이터와 설정

- `app/data/courses.generated.json`: SIS 원본에서 생성된 배포 데이터
- `app/data/majors.ts`: 연계전공 과목표와 공식 출처
- `app/data/core-curriculum.mjs`: 요람 〈별표 1〉 기준 학번별 필수 교양 트랙
- `app/data/equivalents.mjs`: 요람이 「택1」·「중복 수강 불가」로 묶은 동일 인정 과목
- `scripts/import-sis.mjs`: SIS HTML 형식 `.xls` 정규화 도구
- `db/schema.ts`: 최소 사용자 설정과 익명 운영 이벤트 스키마
- `drizzle/`: Neon PostgreSQL에 적용되는 마이그레이션

## Vercel + Neon 배포

1. Git 저장소를 Vercel Hobby 프로젝트로 가져옵니다.
2. Vercel Marketplace에서 Neon을 설치하고 프로젝트에 연결합니다.
3. Vercel이 만든 `DATABASE_URL` 환경 변수를 로컬로 내려받습니다.
4. `npm run db:migrate`로 최초 테이블을 만든 뒤 배포합니다.

```bash
vercel env pull .env.local
npm run db:migrate
vercel --prod
```

`drizzle-kit migrate`는 `@neondatabase/serverless` HTTP 드라이버로는 아무 것도 적용하지 않고 종료 코드 0을 반환합니다. 적용 후에는 반드시 컬럼이 실제로 생겼는지 확인하고, 적용되지 않았다면 `drizzle/*.sql`을 직접 실행한 뒤 `drizzle.__drizzle_migrations`에 `(sha256(파일 내용), _journal.json의 when)`을 넣어 주세요.

`DATABASE_URL`은 저장소에 올리지 않습니다. Preview와 Production 환경에도 같은 이름으로 연결해야 합니다.

## 운영 통계

`GET /api/stats`는 브라우저 기준 사용자 수와 이벤트 이름별 합계만 반환합니다. 프로필 원본 행은 공개하지 않습니다. 이름, 전체 학번, IP, 사용자 에이전트, 에브리타임 링크 또는 토큰은 앱 데이터베이스에 저장하지 않습니다.

## 첫 방문 설정과 학번별 요람

첫 방문 시 입학 연도, 이수학기 수, 소속 대학, 1·2·3전공을 저장합니다. 전공 입력은 현재 개설과목 학과명과 연계전공 목록을 검색하는 자동완성 방식이며, 저장된 값은 다음 방문 때 필터로 복원됩니다. 본문에는 전공 선택 단계를 두지 않고, 저장된 전공을 그대로 필터 조건으로 씁니다.

`app/data/core-curriculum.mjs`가 **2016~2026 요람 〈별표 1〉**을 그대로 담습니다. 입학 연도로 적용 요람을 고르고, 2016학년도보다 이전 학번은 보유한 첫 요람(2016)으로 안내합니다. 요람 안에서 늘거나 빠진 과목은 `from`(적용 시작 연도)과 `until`(마지막 인정 연도)로 표시합니다.

## 필수 교양 이수 판정

요람 체계가 2019학년도에 바뀌었으므로 트랙 구성도 두 갈래입니다.

| 적용 요람 | 체계 | 영역 |
| --- | --- | --- |
| 2016~2018 | 중핵필수 + 중핵필수선택 | 중핵필수 4개(읽기와 쓰기·글로벌 의사소통Ⅰ·서강인성·컴퓨팅 사고력) + 7개 탐구 영역 |
| 2019~2026 | 공통필수 + 공통선택 | 공통필수 5개(서강인성·글쓰기·글로벌 언어Ⅰ·전공·진로 탐색·소프트웨어) + 4개 영역 |

같은 체계 안의 학번별 차이도 요람 그대로 반영합니다. 예를 들어 소프트웨어 영역은 2019~2020학번 `컴퓨팅 사고력`, 2021학번 없음(공통필수 8학점), 2022학번부터 `기초인공지능프로그래밍`입니다.

판정 흐름:

1. 에브리타임에서 가져온 과목명을 트랙별 지정 과목명(과거 과목명 포함)과 비교해 이수 여부를 추정합니다.
2. 사용자가 트랙별 체크박스로 추정 결과를 덮어씁니다.
3. 이수한 트랙의 과목은 개설 시간표에서 제외하고, 남은 트랙의 과목은 전공 과목과 함께 보여줍니다.

체크 결과는 브라우저 상태로만 두고 서버에 보내지 않습니다.

### 소속 대학 기반 자동 판정

`colleges`에 소속별 계열(`stream`)과 요람이 지정한 영역별 필수선택(`pinned`)을 담아 두 가지를 자동으로 좁힙니다.

- 글쓰기 영역: 인문계열 → `인문사회 글쓰기`, 자연계열 → `자연계 글쓰기`
- 영역별 필수선택: 자연과학·공과·소프트웨어융합대학 → `미적분학Ⅰ`, SCIENCE기반 자유전공학부 → `과학도를 위한 파이썬`, 인문학기반 자유전공학부 → `인문학의 세계`

소속을 입력하지 않으면 좁히지 않고 영역 과목을 모두 보여줍니다. 2018학번 이전 중핵필수선택은 모집단위별로 필수 영역 자체가 달라 판정하지 않고 안내만 합니다. 편입·국제·장애학생 예외도 판정하지 않습니다.

## 개발자에게 건의하기

오른쪽 아래 버튼을 누르면 챗봇 형태로 의견을 받습니다. **단방향 접수**입니다 — 분류와 본문만 보내고, 답장 수단(이름·이메일·연락처)은 입력받지도 저장하지도 않습니다. 공개 API는 `POST /api/feedback` 하나뿐이고 읽기 경로가 없습니다. 익명 방문자 기준 하루 10건까지 받습니다.

받은 건의는 `/admin`에서 관리합니다.

```bash
# 관리자 키 만들기 (Vercel 환경 변수 ADMIN_TOKEN에도 같은 값을 넣습니다)
openssl rand -base64 32
```

`/admin`에 키를 입력하면 키 자체가 아니라 `ADMIN_TOKEN`으로 `주제|만료시각`을 HMAC 서명한 값만 `HttpOnly` `Secure` `SameSite=Strict` 쿠키로 남습니다. 만료시각이 서명에 들어 있어 8시간이 지나면 같은 쿠키 값은 통하지 않습니다. 10분 안에 5회 틀리면 15분간 잠깁니다. 목록에서는 분류·본문·작성 시각과 함께 익명 방문자 ID로 이어 붙인 학번·소속을 참고용으로 보여주고, 각 건의를 `새 건의 → 확인 중 → 처리 완료`로 표시할 수 있습니다. `ADMIN_TOKEN`이 없으면 관리 API는 503으로 닫힙니다.

## 동일 인정 과목 (택1 묶음)

요람이 「택1」·「대체 인정」·「중복 수강 불가」로 묶어 둔 과목은 하나만 이수해도 나머지를 들을 필요가 없습니다. `app/data/equivalents.mjs`가 이 묶음을 담고, 제외 목록을 자동으로 넓힙니다. 예를 들어 `경영통계학`만 들었어도 `통계학입문`·`경제통계학`·`응용수학Ⅰ`·`사회통계학`이 함께 빠집니다.

묶음마다 `source`에 요람 원문을 적어 두었고, 근거를 찾지 못한 관계는 넣지 않습니다. 한 과목이 여러 묶음에 속할 수 있습니다 — `미적분학Ⅰ`은 「대학수학」 묶음과 「경제수리기초」 묶음 양쪽에 있습니다.

새 묶음을 추가할 때는 `data/bulletins/sogang-*.txt`에서 `택1`·`중복 수강`·`대체`·`동등한 과목`을 검색해 근거를 먼저 확보하세요.

## 결과 좁히기

- **전공 단위 제외**: 1·2·3전공별로 「이미 다 이수한 전공」을 체크하면 그 전공 과목이 한 번에 빠집니다.
- **교양 표시 전환**: `전체`(필수교양 + 자유교양 210과목) · `필수만`(기본, 남은 필수 교양 영역만) · `숨기기`(전공 과목만).

## 과목 구분 색

시간표와 목록의 색은 「그 과목을 무엇으로 듣는지」를 나타냅니다. 1전공 `#861f1c`, 2전공 `#004f8e`, 3전공 `#6f9453`, 필수교양 `#e3540b`, 자유교양 `#5c2976`. 판정 순서는 1·2·3전공 → 필수교양 → 자유교양이고, 결과에 실제로 있는 구분만 범례에 나옵니다.

## 시간표 행 묶기

행은 **시작 시각**으로만 묶습니다. 종료 시각까지 키로 쓰면 `13:30~14:45`와 `13:30~16:15`가 서로 다른 행이 되어 같은 교시가 갈라집니다 — 개설과목의 시작 시각은 19가지인데 (시작,종료) 조합은 69가지입니다. 각 과목의 종료 시각은 카드에 `~16:15`로 적습니다.

한 교시에 최대 20과목이 겹치므로 캘린더식 레인 배치(칸 병합)는 한 칸이 15px가 되어 쓸 수 없습니다. 그래서 교시 행 안에서는 카드를 세로로 쌓습니다.
